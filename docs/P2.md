## Quick Summary
- **Milestone Name:** Product P2 ("Debugger and Input Expansion")
- **Baseline:** Product P0 and P1 complete baselines (410 tests passing).
- **Core Scope:**
  1. Direct ARM ELF32-LE loading (`ET_EXEC` only; Position-Independent Executables `ET_DYN` deferred post-P2)
  2. ELF symbol support (`SymbolTable`)
  3. DWARF address/source-line mapping (`LineTable`)
  4. Memory Watchpoints (`read`, `write`, `read_write`, committed-boundary, dual observability on Step and Run)
  5. Bounded Step Back / execution history (100 steps, invariant `step_seq`, `state_revision`, lazy memory capture)
- **Feasibility Track (Non-blocking):** Cortex-M research spike (`spikes/p2_cortex_m/`, `P2-R`)
