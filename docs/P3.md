# Product P3 Overview

See the complete canonical specification and implementation roadmap in [docs/milestones/P3.md](milestones/P3.md).

## Quick Summary
- **Milestone Name:** Product P3 ("RISC-V Introduction — RV32I")
- **Baseline:** Product P0, P1, and P2 baselines.
- **Core Scope:**
  1. RV32I little-endian execution on Unicorn 2.1.4 (base 32-bit integer instructions)
  2. RV32I assembly source and addressed disassembly/import input producers
  3. Strict `x0`/`zero` immutability (always 0, user edits rejected, CPU writes suppressed)
  4. Multi-ISA domain boundary refactoring (decoupling Profile Identity from dynamic Execution Mode)
  5. Architecture-owned control-flow boundary (`RiscvControlFlowInterpreter`)
  6. Dedicated RISC-V execution backend (`RiscvUnicornBackend`)
  7. Full reuse of debugger features: Run / Stop, Breakpoints, Memory Watchpoints, Bounded Step Back, Reset, User Baseline State
  8. Profile-driven frontend UI (suppressing CPSR and N/Z/C/V flags for RISC-V sessions)
  9. Full ARMv7-A / Thumb-2 regression preservation
- **Feasibility Spike:** Executed and recorded in `spikes/p3_riscv/` (`probe.py`, `observations.json`)

  - [milestones/P3.md](milestones/P3.md) - Canonical detailed P3 milestone specification and stage plan
  - [SRS.md](SRS.md) - Functional requirements (`P3-FR-001`–`P3-FR-016`) and acceptance criteria (`P3-AC-01`–`P3-AC-24`)
  - [ARCHITECTURE.md](ARCHITECTURE.md) - System architecture, multi-ISA design, domain models, and ADR-026–032
